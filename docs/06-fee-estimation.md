# 報酬の算定（見積ロジック）

**目的は「実務を楽にすること」である。** 案件ごとに考え直すのをやめ、
**同じ入力からは必ず同じ金額が出る**状態を作る。
副産物として、法24条の10（報酬の算定の根拠を明らかにするための見積書。**努力義務**）に
そのまま対応できる。

> **法24条の10は努力義務であり、監督処分の対象ではない**
> （→ [01-legal-requirements.md §1.5](01-legal-requirements.md)）。
> **見積を作っていなくても契約書は作れる。** 画面は警告を出すだけで、止めない。

---

## 1. 何を固定し、何を可変にするか

**告示の略算法を土台にし、事務所ごとの単価と係数で補正する。**
土台と補正を混ぜず、**内訳書には両方を出す。**

| 層 | 内容 | 出どころ | 変わる頻度 |
| --- | --- | --- | --- |
| **① 告示の略算方法** | 標準業務人・時間数の別表、**難易度係数**、費目の構成、**直接経費＋間接経費の倍数（1.1 / 1.0）**、略算方法が使えない場合 | **告示の原文**（コードに定数として持つ） | 告示の改正時のみ |
| **② 事務所の設定値** | 人件費単価、**技術料等経費率**、事務所の補正係数、最低報酬額、端数処理。**告示に定めのないもの**（→ §3.3） | **Firestore の共有設定**（画面から編集） | 年1回程度 |
| **③ 案件ごとの入力** | 建築物の類型、延べ面積、受託する業務の範囲、特別経費 | フォーム | 案件ごと |

> **①をコードに、②を設定に置く理由。** 告示の別表は**法令の写し**であり、
> 誤って編集されては困る。改正時にはテストごと差し替える。
> 一方、人件費単価は事務所の実態であり、**画面から直せなければ使われなくなる。**

## 2. 適用する告示は2本ある

**費目の構成が違うため、1つの計算器に押し込めない**（→ [01-legal-requirements.md §1.7](01-legal-requirements.md)）。

| | **令和6年国土交通省告示第8号** | **平成27年国土交通省告示第670号** |
| --- | --- | --- |
| 対象 | 設計、工事監理、建築工事契約に関する事務、建築工事の指導監督 | **耐震診断・耐震改修**に係る左記の業務、および**建築物に関する調査若しくは鑑定** |
| 業務経費の費目 | 直接人件費・特別経費・直接経費・間接経費 | **直接人件費・検査費**・特別経費・直接経費・間接経費 |
| 直接経費＋間接経費の倍数（略算） | **1.1** を標準 | **1.0** を標準 |
| 略算方法の対象 | 別添二の 15 類型（戸建住宅は第十三〜十五号） | **鉄骨造・鉄筋コンクリート造・鉄骨鉄筋コンクリート造の建築物、又は戸建木造住宅**のみ |
| 別表 | 別表第1の1 〜 第15（床面積 100㎡〜100,000㎡） | 別表第一（S・RC・SRC、500㎡〜7,500㎡）／**別表第二（戸建木造住宅、75㎡〜250㎡で一律）** |

**検査費**は「溶接部の超音波探傷検査、コンクリート供試体の圧縮強度検査その他の設計等の
業務に附随して行う検査を第三者に委託する場合における当該検査に係る費用」（第670号 第二ロ）。
**実費の積上げ**であり、告示第8号では立たない。

> **告示第670号の別表第二（戸建木造住宅）は、75㎡から250㎡までの範囲に対して
> 耐震診断 45 人・時間、耐震改修に係る設計 60 人・時間という 1 つの値である。**
> **補間は不要で、してはならない。** 別表第一は 8 刻みの離散点なので §3.3 ② の補間が要る。

契約種別から自動で選ぶ。

```
seismic_diagnosis          → 告示第670号
seismic_retrofit_design    → 告示第670号
design / supervision       → 告示第8号
inspection / procedure_agency / other → 告示なし（実費積上げ）
```

> **告示第98号（平成31年）は廃止されている。** 告示第8号 附則第2項で確認済み
> （→ [01-legal-requirements.md §1.7](01-legal-requirements.md)）。**参照してはならない。**

## 3. 算定の流れ

> **2026-08-17 改訂: 告示の原文を取得し、算定方法・費目の構成・略算方法の倍数・別表・
> 難易度係数・適用範囲を確定させた**（→ [04-external-services.md §6](04-external-services.md) の
> **未確定事項 C は解消**）。一次ソースは §8。
> 実装側の設計は
> [portal の docs/contract-formatter.md §6](https://github.com/min-nano/portal/blob/main/docs/contract-formatter.md)
> にある。

### 3.1 告示が定める算定方法

```
業務報酬 = 業務経費 + 技術料等経費 + 消費税に相当する額          （告示第8号 第一）

業務経費 = 直接人件費 + 特別経費 + 直接経費 + 間接経費           （同 第二）
技術料等経費 … 業務において発揮される技術力、創造力等の対価      （同 第三）
```

**略算方法**（同 第四）は、業務経費のうち 2 つを次のように置き換えられる。

```
直接人件費          = 標準業務人・時間数 × 一人・一時間当たりの人件費   （第四 イ）
直接経費 + 間接経費 = 直接人件費 × 1.1（標準）                        （第四 ロ）
```

**1.1 は告示に書かれた値である**（第四ロ「一・一を標準とする倍数」。告示第670号では **1.0**）。
直接経費及び間接経費が通常の場合に比べ著しく異なる場合は倍数を調整できる（同 5項）。

**標準業務人・時間数**は別添三の別表が、建築物の類型ごとに床面積の刻みで
**「（一）設計」「（二）工事監理等」×「総合」「構造」「設備」の 6 つの値**として与える。
1 つの数値ではない。別表の値には**難易度係数**（別添三 3〜8項）を乗じる。
これは**告示の一部**であり、事務所の補正係数とは別のものである。

**一部の業務のみ行う場合**は、標準業務人・時間数から行われない業務に対応した
業務人・時間数を**削減**する（第四 3項）。総合・構造・設備を個別に行う場合だけでなく、
**基本設計のみ・実施設計のみ**を含む（技術的助言 5(3)）。
標準業務内容に含まれない追加的な業務は、対応する時間数を**付加**する（同 4項）。

### 3.2 略算方法が使えない場合

**告示と技術的助言が明示的に排除している。検知して略算方法に倒さないこと。**

| 場合 | 根拠 |
| --- | --- |
| **床面積の合計が別表の最小値を下回る／最大値を上回る** | 第四 ただし書、技術的助言 5(1) |
| **増改築、修繕・模様替、設計変更** | 技術的助言 5(1)。標準業務人・時間数は**新築の業務量** |
| 複数の建築物の類型が複雑に混在する建築物 | 同上 |
| 社寺、教会堂、茶室等の特殊な建築物 | 別添二（注）1 |
| 標準設計、複数の建築物に同一の設計図書を用いる場合、特に芸術的性格が強い場合、極めて特殊な構造方法等 | 第一、技術的助言 2 |
| **建築物に関する調査又は鑑定その他の業務** | 技術的助言 2（告示第8号の対象外。→ §7） |

**この場合、内訳書に「告示の略算方法による」と印字しない。** 根拠のない準拠表示をしない。

### 3.3 告示に定めがなく、こちらで決めたもの

**告示は次を定めていない。** 推測を「告示による」と書かず、事務所の決めごととして扱い、
**内訳書でも告示による値と区別して印字する。**

| # | 決めごと | なぜ |
| --- | --- | --- |
| ① | **人件費単価は 1 つ**（技術者区分ごとに持たない） | 別添三 9項が「一級建築士として2年又は二級建築士として7年の経験を有する者」を前提に時間数を定めている。区分ごとの単価を掛けると告示が想定していない値になる |
| ② | **床面積は別表の隣接点で直線補間する** | 別表は離散点（戸建住宅なら 100/150/200/300㎡）で、実案件は必ず点の間に落ちる。**告示は補間方法を定めていない**ので、内訳書に「別表の値を直線補間した」と明記する |
| ③ | **技術料等経費率は「直接人件費＋直接経費＋間接経費」に掛ける**（特別経費には掛けない） | 特別経費は出張旅費・特許使用料等の実費（第二ロ）であり、実費の立替に技術料の上乗せを掛ける説明が立たない |
| ④ | **告示の難易度係数と事務所の補正係数を、内訳書の別の行に出す** | 混ぜると「告示による算定額」が説明できなくなる |
| ⑤ | **最低報酬額を採ったときは、その旨を内訳書に印字する** | 採った理由が書面から読めないと、法22条の3の4 の説明に使えない |

> **技術料等経費に「率」の規定は告示にない。** 告示第三は「技術力、創造力等の対価」と
> 定めるだけで算定式を置いていない。技術的助言 4 も「個別の事情に応じて、契約前に
> 当事者間の協議を行い、定められるのが適切」としている。
> **「技術料等経費率は告示による」と書いてはならない。**

### 事務所の設定値（Firestore）

**告示に定めのないものは、すべてここに置く。告示の値と混ぜない。**

| キー | 内容 | 単位 | 告示に定めがあるか |
| --- | --- | --- | --- |
| `personnel_unit_price` | 一人・一時間当たりの人件費（**区分を持たない**。§3.3 ①） | 円 / 人・時間 | **なし** |
| `overhead_multiplier` | 直接経費＋間接経費の倍数 | 倍率 | **ある**（第8号 1.1 / 第670号 1.0。調整可） |
| `technical_fee_rate` | 技術料等経費率 | 倍率 | **なし**（協議事項） |
| `adjustment_factor` | 事務所の補正係数。**難易度係数とは別**（§3.3 ④） | 倍率（既定 1.0） | **なし** |
| `minimum_fee` | 業務区分ごとの最低報酬額 | 円 | **なし** |
| `tax_rate` | 消費税率 | — | — |
| `rounding` | 端数処理の位置と方向 | — | **なし** |

**金額はすべて整数（円）で扱う。浮動小数点を使わない。**
端数処理の丸め位置（円単位／千円単位）と丸め方向は設定値とし、**内訳書に明記する。**

## 4. 補正を「見えるところ」に置く

**告示による算定額 A と、実際の提示額 B を、内訳書に両方出す。**

```
  告示による算定額（令和6年国土交通省告示第8号 略算法）      3,180,000 円
  事務所の補正（補正係数 0.95）                             △ 159,000 円
  ─────────────────────────────────────────
  業務報酬（税抜）                                          3,021,000 円
  消費税相当額                                                302,100 円
  ─────────────────────────────────────────
  合計                                                      3,323,100 円
```

補正の理由を選択式で持ち、内訳書に印字する（例: 既往の設計図書がある／類似案件の実績がある／
業務範囲を限定している／遠方につき現地確認の回数を要する）。

### 補正係数が 1 未満のときは警告を出す

**法22条の3の4は「報酬の基準に準拠し、及び見積書の内容その他の事情を考慮して、
適正な委託代金で契約を締結するよう努めなければならない」と定める**
（→ [01-legal-requirements.md §1.4](01-legal-requirements.md)）。
告示の算定額を大きく下回る提示は、この努力義務に照らして説明を要する。

> 補正係数が 0.95 を下回っています。告示の算定額を下回る理由を内訳書に記載してください
> （法22条の3の4）。

**ブロックはしない。** 努力義務であり、正当な理由がある場合は当然にありうる。
**理由を書かせることに意味がある。**

## 5. 出力: 業務報酬内訳書

雛形は Google ドキュメント。生成の仕組みは契約書と同じ（→ [05-documents.md §2](05-documents.md)）。

**印字するもの**

| 区分 | 内容 |
| --- | --- |
| 適用した基準 | 告示の名称・番号・年月日、略算方法によること（**略算方法が使えない場合は書かない**。→ §3.2） |
| 前提 | 建築物の類型（別添二の号）、延べ面積、構造、階数、受託する業務の範囲 |
| **算定根拠** | 別表と参照した床面積の刻み（**補間したならその旨**。→ §3.3 ②）→ 標準業務人・時間数（総合／構造／設備 × 設計／工事監理等）→ **告示の難易度係数**（該当する建築物と倍数）→ 業務人・時間数 → 直接人件費 |
| 費目の内訳 | 直接人件費／直接経費＋間接経費（倍数を明記）／技術料等経費（**率は事務所の設定である旨**）／特別経費（＋告示第670号なら検査費） |
| 補正 | 告示による算定額、**事務所の補正係数と理由**（難易度係数とは別の行）、提示額 |
| 消費税 | 税率、税額、税込合計。端数処理の方法 |
| 有効期限 | 既定30日 |

**「報酬の算定の根拠を明らかにするための見積書」（法24条の10）は、この内訳書がそのまま該当する。**

> **見積書そのもの（宛名・件名・金額のある書式）は、当面マネーフォワード クラウド請求書の
> 画面で作る。** 本ツールが作るのは**内訳書**であり、見積書に添付して送る。
> 見積作成のAPI化は後回しでよい（→ [04-external-services.md §2](04-external-services.md)）。

## 6. 実装の置き場所

**計算は `core/`（Rust → wasm）に置く**（→ [adr/0008](adr/0008-implement-as-portal-tool.md)）。

- **画面が入力のたびに金額を出す。** 面積を動かしながら金額を見られることが、実務では効く
- **保存（内訳書の生成）のとき、サーバが同じ .wasm で計算し直して突き合わせる。**
  食い違えば警告を出す。portal の必要壁量ツールと同じ作法
- 告示の別表は Rust の定数表として持つ。**改正時はテストごと差し替える**

```
core/src/fee_kokuji8.rs     令和6年告示第8号の別表と略算法
core/src/fee_kokuji670.rs   平成27年告示第670号の別表と略算法（検査費を含む）
core/src/fee.rs             共通の費目積算・補正・端数処理
```

### テストで守ること

```
- 告示の別表の値が、原文の表と1つも違わないこと（表を丸ごと突き合わせる）
- 告示に計算例があれば、それを再現できること
- 同じ入力から常に同じ金額が出ること（実務を楽にする、という目的そのもの）
- 端数処理: 円未満が出ないこと、丸め方向が設定どおりであること
- 告示第670号で検査費の費目が立つこと（第8号では立たないこと）
- 告示第670号の倍数が 1.0、第8号の倍数が 1.1 であること
- 難易度係数が、別表第1の1〜12の2 と 別表第13〜15 で正しく切り替わること
- 複数の難易度係数に該当するとき、すべての倍数が乗じられること
- 床面積が別表の範囲外なら略算方法に倒さないこと（→ §3.2）
- 補正係数 1.0 のとき、提示額が告示による算定額と一致すること
- 最低報酬額が算定額を上回るとき、最低報酬額が採用され、内訳書にその旨が出ること
```

## 7. 告示の対象外の業務

調査・検査（定期報告等）・手続の代理には業務報酬基準の告示がない。
**実費の積上げ**（業務人・時間数 × 人件費単価 ＋ 経費 ＋ 技術料等経費）で同じ形の内訳書を作る。

- **「告示に準拠」とは書かない。** 根拠のない準拠表示をしない
- 内訳書には「業務報酬基準の告示が定められていない業務であるため、
  当事務所の積算による」と明記する
- **法24条の10の努力義務は、これらの業務にも及ぶ**
  （「設計等の業務に係る契約」＝法23条1項の定義。調査・鑑定を含む。
  → [01-legal-requirements.md §1.5](01-legal-requirements.md)）。
  **書面契約義務が及ばない業務にこそ、見積の努力義務が効く**という非対称を潰さない
